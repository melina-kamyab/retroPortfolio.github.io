Copy images/ to public/portfolio/pathfinder/. Import PathfinderVisuals.jsx and its CSS. The component supports hero, steps, and pricing captures. All headings and captions remain live webpage text; no extra beige background is added. Screenshots retain the source site's own design. PNG copies are supplied alongside web-ready WebP.

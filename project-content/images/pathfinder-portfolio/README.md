# Pathfinder portfolio kit

Copy images/ to public/portfolio/pathfinder-portfolio/. Import PathfinderVisuals.jsx and its CSS. The component supports hero, steps, customer cases, and knowledge hub captures. All headings and captions remain live webpage text; no extra beige background is added. Screenshots retain the source site's own design. The files are supplied as WebP.

Read case-study.md for project-card and case-study copy. Review the editorial notes and remove them before publication. The WebP images capture the live site on 29 October 2026, not an archived version or a reconstruction. Mobile and before screenshots were not available.
